# 阴阳师阵容图鉴 v0.2.0 · 本地解析与官方资料更新

下载 `Onmyoji-Lineup-Atlas-0.2.0-Windows-x64.exe` 后双击运行。适用于Windows x64，无需Node.js或Python；此版本未签名。

## 新增

- 根据指定解析研究实现V0–V3本地解码；支持完整自创二维码文本、二维码图片、裸lineup_data和查询回包JSON。
- 回包按share_key补齐已保存原码，保留名称、用途、备注及来源；解析后可直接保存、重启读取。
- 官方名单、40级6星基础属性、图片与维护公告可每日在线检查，支持手动更新、完整复核、取消和离线缓存。
- 补齐六位主角的10张图片：四位来自网易繁中官网，两位英杰来自BWiki。合计275位式神的936张图片及主角10张，共946张。
- 修复长阵容码和长立绘的详情溢出；无独立觉醒形态的SP等角色显示默认形象，并明确标注。

## 验证与边界

69项Node测试、8项Python测试通过。12组参考向量逐字段一致；实际页面已验证文本解析、二维码导入、回包关联、保存重载和图片显示。实际官方更新通过275条目录检查，并成功下载8张官方主角图片；最终便携EXE完成解析、缓存图片和更新开关烟测，包内容与源码哈希核对通过。

**文字分享码 `|TA|…` 仍需要游戏会话查询。** 程序已支持导入回包，但尚未取得Excel中110个短码的真实回包，因此这些短码实际还原仍为0个。纯数字官方阵容编号、V0含歧义空配置和未核实主角ID仍有相应限制。

原生长方形卡面核验仍为0。御魂业务枚举/数值语义及战斗规则尚未完整核实，相关配置保持待核对。两位英杰的BWiki补图、社区攻略、活动阵容与程序本体不参加官方自动更新。未进行游戏内实战验证。

账号、个人阵容与官方缓存分开保存，旧版资料可继续读取。原始Excel、个人账号样例和用户备份没有进入仓库或Release。附带 `SHA256SUMS.txt`、`RESULTS-v0.2.0.md` 与 `official-update-report.json`。
