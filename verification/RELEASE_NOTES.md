# 阴阳师阵容图鉴 v0.1.0 · Windows预览版

下载 `Onmyoji-Lineup-Atlas-0.1.0-Windows-x64.exe` 后双击运行，无需安装Node.js或Python。适用于Windows x64；本版未进行代码签名。

## 已实现

- 阵容分类与全文搜索、按副本和多个式神筛选、原码保存与本地详情查看。
- 175条本地阵容记录、37个副本用途标签，其中26条有攻略成员文字资料（含部分成员待核实的记录）。
- 官方式神目录275位，动态三页与静态目录ID一致；含SSR石长姬（608）及可独立筛选的SP。
- 936张适用形态的官方立绘和头像通过文件校验；查看稀有度、形态、来源和缺失提示。
- 平安志账号快照导入、覆盖或合并、持久保存、备份恢复，以及有限的式神/技能/御魂库存核对。账号资料只保存在本机。
- 按2026-09-12时点收录当期“拾光永恒”活动资料，所有数据随应用保存。

## 仍未完成

**本版不代表全部原始需求已经完成。** Excel中145处原码、110个唯一原码已完整保留，但指定服务对110个短码全部返回HTTP 400，成功解码数为0。攻略成员资料单独标注，不能当作阵容码解码结果。

原生长方形卡面核验数为0，当前展示的是保留原比例的立绘；阴阳师/英杰形象和多数历史上线日期仍待补齐。账号样例未提供阴阳师/英杰及当前穿戴归属；库存搜索和不完整配置的结果会显示待核对。副本方案仍有缺口，尚未进行游戏内实战验证。

## 验证

31项Node测试及8项Python测试通过。3份真实账号导出均完成本地解析；936张适用图片通过哈希、完整解码和尺寸校验。已实际操作浏览器界面，并启动最终便携EXE验证：175条阵容、275式神、5个页面，首页24张卡片无破图，程序正常退出。发行包通过内容隔离与关键文件哈希核对。

下载附件 `RESULTS.md` 和 `coverage.json` 查看具体计数、测试边界与未完成项；`SHA256SUMS.txt` 可核对下载文件。原始Excel和个人账号导出未上传仓库或Release。
