# v0.5.0：自动解析、账号分页与御魂计算

- 登录并选定查询角色后，自动解析库内未解析原码，逐条保存在本机。「阵容库」「阵容码查看」均有进度、暂停和继续入口。已保存内容复用缓存，单条可重新解析，并提示同码60秒冷却。
- 修复大账号式神列表只能看到一部分的问题，支持60/120条分页、名称/ID搜索与素材筛选。补齐奉为达摩（ID 412）等5种培养素材名称。
- 导入、切换账号或解析完成后自动挑选阵容，按已知条件差距排序；逐成员展示角色、技能、套装、主属性与八项面板的要求、实际值和差距。
- 内置六位置御魂计算器，可深入计算全队，检查式神及御魂实例重复占用和原码最高属性次序。缺口建议给出优先兑换/更换的套装、位置、主属性与强化方向。
- 对照用户提供的2.8.84 APK核对属性单位、觉醒加成和套装机制，修正防御二件套、无刀取与首领固定属性口径。

主角、契灵、当前穿戴与其他导出缺项仍明确提示核对；有限搜索未命中不等于无法配出，强化副属性不保证命中。详情与计算器不会把未核对的整队宣称为完全符合。

关闭正在使用的旧版后运行 Setup 安装包。原有本地账号、阵容和官方缓存保留；旧版已保存TA内容在本机升级映射，无需因此重新联网查询。安装包未签名。

具体验证方法、三份账号数量和程序验证结果见随发布附带的 `RESULTS-v0.5.0.md`。
