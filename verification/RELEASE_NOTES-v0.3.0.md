# 阴阳师阵容图鉴 v0.3.0

下载 `Onmyoji-Lineup-Atlas-0.3.0-Windows-x64.exe` 后双击运行。Windows x64 便携版，无需安装 Node.js 或 Python；程序未签名。

- 阵容详情中的式神与阴阳师保持单行并排。默认窗口可直接比较六名成员，小窗口可横向滚动或点击左右按钮。
- 修复复制失败：列表和详情共用桌面原生剪贴板接口，等待写入完成后显示“已复制”；详情新增复制按钮。
- 采用宣纸底色、朱砂按钮、描金边框与墨色侧栏，配合现有游戏立绘；没有额外生成图片。
- 删除20条没有阵容码的参考记录，保留155条有码阵容、35个副本用途和6条有成员文字资料的记录。Excel的110个唯一原码和145处来源均完整保留。
- 升级启动时清理个人库里的无码阵容，恢复备份时跳过无码记录；手工配置和结构化导入需提供非空 `code`。账号和御魂资料保留。

关闭旧版后运行新版即可使用同一份本地账号库，移动EXE不需要重新导入账号。可先通过侧栏导出个人备份。

`|TA|`分享键仍需游戏查询回包才能还原成员，未取得回包的原码继续保留并标为待解析。该限制与复制功能无关。原生卡面、未核实御魂语义和游戏内实战验证仍有缺口。

具体检查结果见附件 `RESULTS-v0.3.0.md`；下载文件校验值见 `SHA256SUMS.txt`。
