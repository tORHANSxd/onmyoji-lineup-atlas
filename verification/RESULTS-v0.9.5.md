# 0.9.5 验收记录

本轮验证平安志 `yys-desktop-cache-v1` 桌面缓存快照的导入，保留 `mumu-snapshot-v1` 兼容，并覆盖新旧库存交叉合并、后台重建与备份恢复。

## 数据核验

- 新样本含 3,232 个式神实例、3,893 件御魂、350 个御魂预设。原有三个样本共 7,168 个式神、4,257 件御魂、356 个预设，四份文件均通过逐项核验。
- 比较每个实例、技能 ID 和等级、御魂位置/强化/星级及主副属性；新样本的 3,230 份实例具备对应游戏基础规则，其余 2 份保留原值，不虚构规则。
- 五条副属性御魂、固定属性标记、空预设和五件预设均保留。无 `scope`、区服名称为空及穿戴状态未知按现有规则处理，不作额外推断。
- 原始扩展集合及重复任务记录在序列化和备份恢复后保持一致，堆叠素材单独计数，不视为可上阵实例。
- 样本只在本机读取。仓库记录使用合成数据或匿名统计，不包含真实账号、实例 ID、原始快照与登录凭据。见 [匿名样本核验](snapshot-v095.json)。

## 自动检查

- 262 项 Node 测试通过。新增用例在修复前确认格式被拒绝；只补导入入口后，三种涉及桌面缓存的合并组合仍失败，修正原始列表写回后全部通过。
- 覆盖四种新旧格式合并组合、重复与损坏记录拒绝、数量/范围核对、后台导入、备份恢复和缓存重建。
- 55 项 Python 测试通过。
- 43 项 Electron 界面检查通过，覆盖真实文件导入入口、跨格式合并、备份往返、重启、保存失败及不同视口和缩放。见 [界面报告](optimization-ui-v095.json)。
- 发布复测发现旧弹窗的延迟 `close` 事件会清空重新打开的备份预览。用真实弹窗关闭/重开建立稳定失败用例，修复后新预览保留；没有通过增加固定等待或删减断言掩盖问题。

## 构建与附件

- 最终安装包的 2,064 项源码/资源校验、133 项运行时文件校验与协议源码校验通过；包内禁止包含的私有目录和文件为 0。见 [包审计](package-audit-v095.json)。
- 解出最终安装包后，208 个文件与构建输出逐文件一致；隔离启动、离线入口及未授权操作拦截通过，原安装信息和合成库存保持不变。见 [安装包检查](installer-v095.json) 与 [启动记录](electron-v095-payload-smoke.json)。
- 免安装 ZIP 使用 UTF-8 中文文件名，208 个文件逐项 SHA-256 一致。见 [免安装检查](portable-v095.json)。
- 没有执行实际安装、覆盖安装或卸载；这些结果不能代替对应实机验收。
