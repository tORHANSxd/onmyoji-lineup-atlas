# v0.3.1 安装包验证记录

验证日期：2026-09-12。本次将发布形式从便携版改为Windows x64 NSIS安装包，应用功能和数据格式沿用v0.3.0。

## 安装行为

- 使用中文安装向导，支持选择安装目录，默认当前用户安装。
- 创建桌面和开始菜单快捷方式，以及Windows应用卸载项。
- 安装后从所选目录直接运行应用，不再每次启动便携包进行解压。
- 保持 `appId`、`productName` 和包名不变，继续使用原来的账号库、个人阵容及官方缓存路径；默认卸载保留用户数据。
- 原有界面、155条有码阵容、TA解码及复制功能保持不变。

## 实际安装、运行和卸载

使用最终发布的 `Onmyoji-Lineup-Atlas-Setup-0.3.1-Windows-x64.exe` 执行验证，而非单独解包后的程序。

测试前检查该应用的HKCU/HKLM安装项、桌面/开始菜单快捷方式和正在运行的进程，均不存在，避免覆盖已有安装。安装位置限定在工作区的独立测试目录，路径包含中文和空格。

1. 安装包以 `/S /currentuser /D=...` 实际安装成功，退出码0。安装目录包含应用、资源和卸载器；注册表版本为0.3.1。
2. 桌面与开始菜单快捷方式均创建，目标准确指向测试安装目录中的程序。安装后的 `app.asar` 与构建结果哈希相同。
3. 从安装目录启动程序，使用独立合成账号库执行生产IPC烟测。156条阵容（155条内置加1条测试记录）、275位式神、6位主角、1个合成账号正常读取；六名成员保持单行。长短阵容码复制后读回一致，12个主角图片元素无破图，官方更新设置往返成功，进程退出码0。
4. 运行同一安装包进行重复安装，退出码0，应用仍存在，合成账号与阵容文件的SHA-256保持一致。
5. 运行安装生成的卸载器，退出码0；应用、安装注册表项和两个快捷方式均移除。合成账号库保留。
6. 在卸载器实际使用的两个默认AppData目录中创建独立临时标记，卸载后标记内容保持一致，验证默认卸载不会删除这些数据目录。测试不读取其中的个人账号文件；标记随后清理，原本不存在的目录仅在空目录时移除。

完整结果见 `installer-v031.json`、`electron-v031-installed-smoke.json`；可复用验证脚本为 `tools/verify-installer.ps1`。脚本遇到既有安装、快捷方式或正在运行的程序时会拒绝覆盖。
