# 0.9.4 验收记录

本轮针对 2026-09-23 平安志导出兼容与库存导入性能。仍支持旧版 mumu-snapshot-v1；新快照的格式标记及核心式神、御魂字段未变。

## 数据核验

- 三份授权本地文件分别含 2,574 / 4,163 / 431 个式神实例，1,883 / 1,590 / 784 件御魂，176 / 140 / 40 个御魂预设。
- 逐项比较所有实例、技能 ID 和等级、御魂位置/强化/星级及全部主副属性；核对 7,165 份可取得游戏基础规则的实例属性。其余 3 份实例原值同样保留，未虚构基础规则。
- 扩展集合在原始数据中完整保留并往返备份，包含资源、堆叠素材、碎片、结界卡、传记、任务与阴阳寮。任务数组重复键保留；未知 tuple 列不猜业务含义。
- 3,978 个堆叠素材单独计数，没有扩展成战斗实例。来源提醒显示；未采集、空集合、排除记录和数量不符分别处理。
- 本仓库只有合成测试和匿名统计，不包含这三份私有文件、账号身份、实例 ID 或登录凭据。见 [样本核验](snapshot-v094.json)。

## 自动检查

新增用例先在旧实现观察到扩展字段缺失、未采集御魂误判为缺少；独立审查发现的“新版增量导入旧版后丢失附加记录”也有修复前失败及修复后通过的回归记录。

- Node 测试：254 项通过，包含旧版兼容、完整性判断、混合批量失败、增量合并、后台校验、备份/重载及原子写入。
- Python 测试：55 项通过。
- Electron 界面：40 项通过，包含真实导入入口、采集摘要、提醒转义、旧缓存重载、备份恢复、失败保存及 720–1440 像素/200% 缩放。见 [界面报告](optimization-ui-v094.json)。
- 压力验证使用 3,000 条合成阵容、5,000 个合成式神。原库存保存会在界面线程复制全部未变阵容，单次同步复制约 0.54 秒；修复后账号变更只传输状态中的非阵容字段，后台原子保存时复用已有阵容。具体计时见 [性能报告](performance-ui-v094.json)。

## 构建与交付

安装包内容与本次源码逐文件核对；安装包解出的程序用隔离目录启动；免安装 ZIP 采用 UTF-8 文件名，并逐文件核对 SHA-256。相关结果见 [包审计](package-audit-v094.json)、[安装包检查](installer-v094.json) 与 [免安装检查](portable-v094.json)。

教程按用户要求复用 v0.9.3 的 32 页 PDF，文件名仍为 Yuqi-Guide-0.9.3.pdf，SHA-256 为 7ebbc4cc3a0933b0ececa1eeae4305a2a836aa52c91c3107e2fe2db6c5017313。正文和截图没有重新编写，新增采集摘要以软件界面为准。版本更新记录仅放在 GitHub Release 页面，README 保留下载与使用说明。

## 验证边界

扩展 tuple 仅保留原值与集合计数；未确认的列不用于阵容计算。不把未采集等同于账号没有。完整性证据不足时不能证明全局最优或无解。

本轮没有进行手机扫码、游戏内导入、全部官服/渠道服/iOS/安卓组合、实际覆盖安装与卸载验证。此前实机边界仍适用。本轮没有更改登录协议、阵容编码或游戏规则。
