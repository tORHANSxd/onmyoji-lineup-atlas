# 阴阳师阵容图鉴 v0.3.1 · 安装版

下载 `Onmyoji-Lineup-Atlas-Setup-0.3.1-Windows-x64.exe`，双击按中文安装向导操作。

- 支持选择安装目录，默认当前用户安装。
- 创建桌面及开始菜单快捷方式，安装后程序文件保存在所选目录。
- 支持从Windows“已安装的应用”中卸载；默认保留账号、个人阵容和官方资源缓存。
- 旧便携版用户关闭旧程序后安装即可，继续读取原来的本地账号库。
- 沿用v0.3.0的单行阵容详情、复制修复和宣纸朱砂界面，内置155条有码阵容。

本安装包包含运行所需程序与资源，无需另装Node.js或Python。适用于Windows x64；程序未签名。

验证结果见附件 `RESULTS-v0.3.1.md`，文件校验值见 `SHA256SUMS.txt`。
