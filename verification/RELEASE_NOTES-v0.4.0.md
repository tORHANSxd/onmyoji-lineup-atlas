# 阴阳师阵容图鉴 v0.4.0 · 扫码查询阵容码

`|TA|…` 文字分享码现在可以在应用内完成网易扫码授权、选择已有角色、查询阵容并解析保存。自创二维码和完整 `lineup_data` 继续支持离线解析。

1. 安装后进入「阵容码查看」，粘贴文字分享码。
2. 展开扫码登录，加载服务器并获取二维码，用阴阳师手游内的「扫码登录」扫描和确认。
3. 选择本次账号的已有角色，点击「解析阵容码」，确认详情后保存。也可从阵容详情点击「解析此阵容码」。

修复了账号对象释放被误判为角色断开的问题；每次查询重新验证角色归属，并核对响应分享键。保存解析结果时保留原码及已有名称、用途和备注。

登录模块已随 Windows x64 安装包提供，无需安装 Python。登录凭据只保存在本次运行的内存中，退出登录或关闭程序会清除；升级后需重新扫码。原有本地账号、个人阵容和缓存继续保留。

验证通过：81 项 Node 测试、22 项 Python 测试；真实扫码读取到 2 个角色，示例阵容连续两次查询均返回 6 个位置；实际安装、已安装程序启动、覆盖安装和卸载验证通过。

当前扫码支持网易账号；其他渠道登录、纯数字 `#TA#` 官方阵容编号和未核实的御魂业务计算仍有限制。内置的其余分享码未逐条在线验证。完整记录见附件 `RESULTS-v0.4.0.md`。

下载 `Onmyoji-Lineup-Atlas-Setup-0.4.0-Windows-x64.exe`，关闭旧程序后按中文向导安装。程序未签名，文件校验值见 `SHA256SUMS.txt`。
