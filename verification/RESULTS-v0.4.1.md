# v0.4.1 启动登录验证

验证日期：2026-09-12。

## 行为与隐私

启动默认仅显示扫码页，自动加载官方服务器列表并生成登录二维码。只有网易账号认证成功后才读取本地账号与阵容文件并开放软件；没有跳过按钮或生产测试绕过开关。认证成功不要求已创建角色，文字分享码查询仍需要选择本次账号的已有角色。

登录页说明登录凭据不写入本地文件，不上传开发者或第三方服务器；认证、角色读取与网关连接仍需向网易官方服务发送必要凭据，不能声称完全不联网传输。用户主动导入的平安志库存及保存的阵容继续在本地持久保存。登录账号与库存账号没有强制绑定，可以使用自己的小号或经授权使用的小号。

退出登录或认证失效时，软件隐藏并禁用业务界面，关闭详情窗口，清空当前视图和内存中的业务状态，停止匹配任务。桌面业务接口验证认证状态与会话编号；退出前尚未完成的导入、文件对话框和排队保存不能在新会话中继续提交。磁盘中已保存的资料保留，重新扫码后重新加载。

- 界面回归确认启动自动请求二维码；仅扫码但未确认时不读资料；认证完成才进入；登录小号与合成库存账号不同仍可使用；账号管理可返回软件；退出关闭详情并清屏；重新登录重新读取资料；认证失效重新锁定；旧会话的慢速导入不会在新会话中保存。

本轮未重复要求用户手机扫码。真实手机授权与阵容查询沿用 v0.4.0 同一登录协议及冻结运行时的验证证据；本轮没有修改 Python 登录协议和令牌处理。v0.4.0 的 22 项 Python 测试和两次真实六位置查询见 `RESULTS-v0.4.0.md`。
