# 阴阳师阵容图鉴 v0.4.1 · 启动扫码登录

软件每次打开都会先显示扫码页，并自动获取网易官方登录二维码。在阴阳师手游内扫码并确认登录后，软件才载入本地资料、开放阵容库及其他功能。退出登录或认证失效后会立即返回扫码页。

- 启动页明确说明：登录凭据仅用于本次会话，不保存到本地文件，不上传开发者或第三方服务器；认证及阵容查询仅与网易官方服务通信。主动导入的平安志库存与保存的阵容仍仅保存在本机。
- 无需使用主号，可以使用自己的小号或经授权使用的小号；登录账号与用于库存核对的账号可以不同。
- 左侧「登录账号 / 切换角色」可更换查询角色、切换账号或退出登录。
- 未登录时同时限制界面与桌面功能接口；退出后取消未完成的旧会话导入，防止重新登录后写入旧结果。

关闭旧程序后安装 `Onmyoji-Lineup-Atlas-Setup-0.4.1-Windows-x64.exe`，原有本地库存、个人阵容和缓存继续保留。此版本不提供跳过登录或离线启动入口；完成本次登录后，已保存资料与完整阵容内容可继续在本机查看和解析。

验证结果见 `RESULTS-v0.4.1.md`，校验值见 `SHA256SUMS.txt`。仓库与安装包均已公开；适用于 Windows x64，程序未签名。
