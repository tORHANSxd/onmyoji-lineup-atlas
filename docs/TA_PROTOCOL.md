# TA 阵容解析说明

本版依据用户指定任务 `01a093c9-4254-7980-ba58-9da498e7c913` 的研究成果：`onmyoji_ta.py`、`test_vectors.json`、`bytecode_evidence.txt`。本仓库不分发APK、游戏字节码或游戏登录凭据。测试夹具使用 `test-player`、`test-0` 等虚拟标识。

## 两种分享路径

`|TA|<share_key>` 是服务器分享键。v0.4.0 已接入研究任务实测成功的网易扫码协议：设备登记、手机确认、MPay 令牌兑换、`login_with_sdk`、角色选择，然后调用 `lineup_assisant_logic.get_share_lineup_data`。返回的 `lineup_data` 继续交给同一个本地解码器。无需在电脑启动完整游戏客户端；不能仅凭分享键离线还原。

v0.4.1 起，软件每次启动自动显示扫码页并获取二维码，官方账号认证成功后才载入本地资料并开放功能。所有业务 IPC 同样验证当前认证状态；退出或认证失效后立即锁定，旧会话的延迟结果不能进入新会话。登录账号与本地导入的库存账号可以不同；查询角色必须属于本次扫码账号。未选角色仅限制文字码查询，不把已通过官方验证的账号当作未登录。

登录模块随安装包提供，通过私有标准输入/输出管道与 Electron 通信，不监听本地 HTTP 端口。服务器分类、搜索、已有角色和角色名称来自官方目录及本次登录结果。只支持网易账号授权，目录中的其他渠道分类不表示已实现对应渠道登录。

每次查询使用内存中的本次令牌重新建立连接，并重新核实当前服务器返回的角色归属。查询成功、失败后均关闭该连接，避免空闲会话失效。点击退出登录可中断进行中的操作并结束登录进程；关闭应用同样清除凭据。登录令牌、设备密钥、SDK 授权对象不会写入账号库、备份或日志。用户主动保存的阵容内容仍可离线使用。

2026-09-12 本工具的冻结登录模块已真实扫码成功，读取到2个角色，并在服务器15012连续两次成功查询 `|TA|d902c7045f350394d41df622c66e398a`，结果为V3「个突/寮突」的6个位置。该验证发现并修复了旧研究代码的生命周期边界：`destroy_entity` 可能是账号对象释放，只有目标为当前角色的销毁才表示角色会话结束。查询回包还必须满足 `err=0`、分享键与本次输入完全一致。

可导入自己取得的查询响应：

```json
{
  "err": 0,
  "share_key": "原始文字分享键，不含前缀",
  "lineup_data": "完整Base64内容"
}
```

如同时提供 `code`，它必须与 `share_key` 一致。没有分享键时只保存为自创二维码文本，不能自动关联某个短码。数组表示批量回包，解析全批成功后才合并保存。

`#TA#<payload>` 自创二维码的内容可直接在本机解码：严格Base64 → zlib → MessagePack整数键映射 → 按协议版本展开压缩字段。纯数字后缀是官方阵容编号，需要官方配置，不能当作压缩内容。

## 已实现的契约

- V0–V3、缺省版本V0；保留 `phconf` 和展开后的 `hconf`。
- 槽位、式神/阴阳师类型、技能ID/等级、觉醒、星级/等级、御魂字段、契灵、AI技能、最高属性、分数、实例ID与扩展字段。
- MessagePack中的BSON扩展42/43/44；时间保留微秒精度，二进制采用显式Base64对象保存。
- 最大输入32 MiB、最大解压16 MiB；拒绝截断、zlib尾随内容、未知版本、错位槽位及非整数顶层字段。
- 12组参考向量分别覆盖各版本的常规样本、扩展字段和null字段。另有损坏输入、关联不符、解压限额和合并保留元数据测试。

V1–V3按其字段结构判断角色类型。V0有御魂/契灵配置时可区分；空配置需要完整且经过核验的阴阳师ID表，现有资料不足时拒绝猜测。目前仅核实晴明ID10，其他主角ID仍显示原始编号。独立解析函数支持调用方显式传入 `yysIds`，普通界面不接受未经核验的自动映射。

## 解析与计算的边界

v0.5.0对照用户提供的2.8.84 APK静态数据与计算逻辑，落实了 `criteria`、`two_suit`、`limit`、`highest_limit` 的已支持语义。内部主属性位置1/3/5对应实际2/4/6号位；重复套装数量相加，属性两件套是指定套装之外的额外要求；暴击、暴伤、命中、抵抗的范围按百分数换算。详见 [御魂计算口径](SOUL_CALCULATOR.md)。

原始字段始终保留。契灵、主角、AI技能、保留当前穿戴等不能由库存证实的条件仍单列核对项；协议解压成功不代表这些条件或游戏实战已经满足。旧版已保存TA内容在本机重新映射为新版条件，无需为映射升级重复查询。

登录选定已有角色后，自动扫描未解析原码，按码去重并逐条查询。查询起点至少间隔2.5秒，同码至少间隔60秒；成功结果逐条落盘。暂停或限流保留既有成果；注销取消排队任务，旧会话迟到结果不可提交。已有本地解析结果可以直接查看，用户显式重新解析才重新请求。

二维码的作者/实例标识属于原始内容的一部分，完整JSON导出会保留。请仅分享自己允许公开的阵容资料。
