## 自上一公开版本以来的主要变化

- **制作器对齐游戏规则**：首位固定阴阳师／英杰，副本决定 1+5 或 1+6 位置；技能采用真实名称、图标、官方词条、鬼火消耗和逐级说明。默认拥有全部阴阳师／英杰／契灵，等级和配置按阵容设置。移除游戏不支持的任意差值／倍率关系编辑与计算，保留原生面板范围和最高属性约束。
- **导出与查询修复**：导出前必须选择合法的游戏原码副本，并检查成员、御魂和技能配置。查询前按客户端流程尝试初始化阵容助手，区分功能未开放、会话问题、临时失败和过期码；未确认存在统一的最低角色等级。
- **大量阵容处理**：大 JSON、编解码与二维码操作移到后台；查询结果逐条增量保存，复用分类和库存索引，降低重复计算与界面重绘。可按筛选结果批量精算和暂停。
- **管理与分类**：支持复选、跨页全选、批量重新解析／删除及多种排序；手动多副本归属优先于其他规则，游戏原码列表以外的用途标为扩展副本。整理 373 条预设用途，仍有 45 条等待登录补齐解析、1 条用途待核对。
- **备份与复位**：恢复保留本机独有阵容；同名、同码或同 ID（含内置预设）的重复组按最新有效时间保留，同时间优先本机。全库复位展示范围并倒计时 5 秒，清除全部自建／导入、目标与草稿，恢复内置预设，保留库存和登录账号。
- **登录与界面**：默认选择可用列表中等级最低的角色，无角色时提示先在游戏创建。采用墨褐、象牙白和金色的周年风格，移除活动海报与重复活动元素。

## 游戏导入方式

- `#TA#` 是完整二维码数据，可离线生成二维码，在游戏阵容助手的二维码入口识别。不要把完整数据直接粘贴到只接受官方短码的游戏文字入口。
- `|TA|` 是官方文字短码，需要登录角色后主动调用分享功能生成。完整码本身不能反推出原来的官方短码。
- 旧版缺少合法副本而生成的错误二维码／短码，需要在新版选好原码副本后重新生成；已分享的旧短码不会随本地修改自动更新。
