# 阴阳师阵容图鉴

Windows x64 本地工具，使用 Electron。内置国服 PVE 阵容原码、攻略参考方案、官方式神目录和形象资源，支持平安志账号导入与库存核对。数据截止日期固定为 **2026-09-12**，并非实时更新服务。

## 下载与使用

从本仓库 **Releases** 下载 `Onmyoji-Lineup-Atlas-0.1.0-Windows-x64.exe`，双击运行。无需安装 Node.js、Python 或单独启动服务器。此版本未购买代码签名证书，Windows 可能提示发布者未验证。

1. 在「阵容库」按分类、副本、任意文字或多个式神筛选；多个式神为“同时包含”。
2. 「阵容码查看」可粘贴原码，读取已有本地详情，补充名称用途后保存。联网解析需主动点击，发送的内容只有当前阵容码。
3. 在「我的账号」导入平安志 `mumu-snapshot-v1` JSON。账号按区服ID和账号短ID区分，式神按实例ID保存；同类型多只式神不会合并成一只。
4. 默认以新快照替换同账号，勾选增量合并时保留未再次出现的旧资产。导入后重启仍可使用。
5. 回到阵容库选择账号，点击「检查我的阵容」。详情可查看逐成员缺口以及候选御魂ID、面板和不重复的全队分配。
6. 「式神图鉴」支持稀有度、SP开关、联动/呱/素材类别、形态与中文名搜索。详情包含来源、尺寸和文件校验值。

侧栏可导出和恢复备份。**备份包含账号资料**，用于个人保存，不应当作公开阵容JSON上传。程序没有账号上传、登录、遥测或自动更新功能。

## 本版明确的限制

- 用户提供的 Excel 共 **145 处原码、110 个唯一原码**，原码、用途、备注、作者、原文链接及源行已完整保留。
- 指定方法 A 服务对这110个 `|TA|` 短码全部返回 HTTP 400 / “阵容码不是有效的 Base64”，**成功解码0个**。不能在缺少算法或后端映射时从32位值反推出真实配置，也没有把它改成 `#TA#` 再冒充成功。
- 一部分成员与要求从攻略文字另行整理，并标为“参考方案”。这些资料不是阵容码解码结果。要求完整性、当前版本实战表现与替代方案仍需要核对。
- 图鉴动态名单3页与静态名单均为275条，ID集合一致；石长姬经两份官方名单核实为 **SSR / 608**，9月9日正式上线。SP独立开关，联动、呱、素材标志与稀有度分开保存。
- 当前取得的是官方立绘、头像及小样书签。**原生长方形卡面核验数为0**。立绘在矩形区域保持原比例展示，没有裁头像、拉伸立绘或复制初始图冒充觉醒图。没有宣称“全部收齐”。
- 官方名单不是完整的历史上线证明；除本轮核实的新式神外，历史正式上线日期尚未逐项补齐。N/SP/UR及ID401的无独立觉醒状态参考官方页面模板，部分N呱的属性接口结果与此存在冲突，保留记录。
- 所给三份平安志样例没有阴阳师/英杰及当前穿戴归属。本版只报告它们未提供，不能从阵容或预设猜测账号拥有状态。
- 御魂基础面板仅使用官方接口中对应 **40级6星、具体觉醒状态** 的数据；低等级、低星级与未知字段不擅自推算。
- 大仓库采用有上限的候选搜索。找到的方案检查六个位置、六个御魂实例、套装件数和数值条件，并检查全队式神/御魂实例不重复；搜索未命中只会标为待核对。跨成员配速、最高属性、契灵技能与战斗增益没有完整建模，不等同游戏实战模拟器。
- 当前仍有副本缺少可核实的结构化方案。程序「来源与覆盖」展示覆盖矩阵，区分只有原码、有成员参考与完全未收录。

「拾光永恒」活动按国服维护公告核对为9月9日维护后至9月29日23:59；「炼石成金」9月16日10:00开启，因此未列为9月12日已开放。

完整计数和验证记录见 [覆盖报告](verification/coverage.json) 与 [验证记录](verification/RESULTS.md)。

## 数据保存在何处

正式桌面版使用 Electron `app.getPath('userData')` 下的 `library-v1.json`，Windows通常位于 `%APPDATA%/阴阳师阵容图鉴/`。移动EXE不会删除该文件。保存通过临时文件与原子替换完成，写入失败会在界面提示。

代码、官方图片与公开来源数据在发行包中；原始Excel、用户平安志示例、个人导出备份均不进入仓库或Release。仓库当前为私人仓库。

## 开发与构建

```powershell
npm ci
npm test
npm start
npm run dist
```

`release/` 输出便携版EXE。Electron主进程使用上下文隔离、沙箱、关闭Node集成，并限制页面导航及IPC来源。所有图片与日常查询均离线运行。

已生成的 `data/bundle.json` 可直接使用。重新聚合已有本地数据：

```powershell
npm run build:data
```

维护采集脚本需要 Python、Pillow、openpyxl。它只访问代码中的公开域名白名单，不读取账号文件；采用限速、响应大小限制与可续跑缓存。官方服务拒绝访问或限流时会停止，不绕过访问控制。

```powershell
python tools/collect.py roster
python tools/collect.py sample
python tools/collect.py full
python -m unittest discover -s tests -p "test_*.py"
```

执行Excel采集、解码探测、重新整理攻略前需自行提供相应原始资料；这些私人输入和完整网页正文不随仓库分发。`data/references.json` 保存公开来源与校验值，`data/mechanics.json` 保存已核对的套装/指标映射。
