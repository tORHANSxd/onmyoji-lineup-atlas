# 阴阳师阵容图鉴

Windows x64 本地工具，支持 PVE 阵容检索、TA 阵容内容解析、形象资料在线更新与平安志库存核对。**阵容攻略快照截至 2026-09-12；官方名单、基础属性、图片和维护公告可以在线更新。**

## 下载与使用

从 [v0.4.0 Release](https://github.com/tORHANSxd/onmyoji-lineup-atlas/releases/tag/v0.4.0) 下载 `Onmyoji-Lineup-Atlas-Setup-0.4.0-Windows-x64.exe`，双击进入中文安装向导，可选择安装目录；安装完成后从桌面或开始菜单打开程序，无需安装 Node.js 或 Python。此版本未签名。仓库为私人仓库，下载需要登录有权限的 GitHub 账号。

安装包默认安装到当前用户，可在Windows“已安装的应用”中卸载。账号库和官方缓存保存在独立用户数据目录，卸载默认保留；从旧便携版切换时，关闭旧版后安装即可，无需重新导入账号。

1. 在「阵容库」按分类、副本、文字或多个式神筛选；多个式神表示同时包含。
2. 「阵容码查看」支持粘贴 `#TA#` 自创二维码文本、裸 `lineup_data`，或导入二维码图片。完整内容自动在本机解析，点击保存即可进入个人阵容库。
3. `|TA|…` 文字分享码支持直接查询。在「阵容码查看」展开扫码登录，加载服务器、使用阴阳师手游内的扫码登录确认，然后选择已有角色并点击「解析阵容码」。点击保存会补齐原码详情，保留已有名称、用途和备注；也可从阵容详情点击「解析此阵容码」进入。
4. 在「我的账号」导入平安志 `mumu-snapshot-v1` JSON。相同类型多只式神按实例 ID 保留；默认替换同账号快照，可选增量合并。重启后资料仍在。
5. 选择账号后点击「检查我的阵容」，查看式神、技能与已建模御魂要求的缺口；不完整条件显示待核对。
6. 「式神图鉴」的资源对象可切换为「阴阳师 / 英杰」。所有图片保持原始比例并注明来源。
7. 「来源与覆盖」可手动更新官方资料、停止更新、关闭每日自动检查，或选择完整复核已有图片与属性。

阵容详情中的式神与阴阳师保持单行并排，小窗口可使用左右按钮或横向滚动查看；列表和详情均支持复制原码。界面采用宣纸、朱砂与描金配色，使用本地已有游戏立绘。

本版删除20条没有阵容码的参考记录。升级启动时会清理个人库中的无码记录；恢复备份时跳过这些记录。账号、御魂和带原码的未解析阵容保留。新增手工配置与结构化导入必须提供非空 `code`。

侧栏支持导出和恢复备份。**备份包含账号资料**，请个人保存；不要当作公开阵容 JSON 上传。平安志库存文件保存在本机。扫码查询会向网易官方认证、角色和网关服务发送本次登录所需的凭据及指定分享键，凭据仅保存在内存；不提供密码输入框、不保存登录状态。退出登录或关闭程序会清除本次凭据。自创二维码解码与已保存阵容查看不联网，官方更新只请求公开资料。

## TA 解析范围

| 输入 | 行为 |
|---|---|
| `#TA#<Base64>` 自创二维码文本 | 本地 Base64 → zlib → MessagePack → V0–V3 展开 |
| 裸 Base64 `lineup_data` | 同上 |
| 阵容二维码图片 | 本机识别二维码，然后调用同一个解析器 |
| `{ "share_key": "…", "lineup_data": "…" }` JSON | 解码并关联原始文字分享码；支持 JSON 数组批量导入 |
| 文字分享码 `\|TA\|<share_key>` | 网易官方扫码授权 → 选择已有角色 → 查询并本机解码；可保存离线使用 |
| `#TA#<数字>` 官方阵容编号 | 提示需要游戏官方阵容配置表 |

实现依据用户指定的解析研究任务与 12 组参考向量，细节见 [TA 协议说明](docs/TA_PROTOCOL.md)。支持成员、技能、觉醒、御魂配置、契灵、AI 技能及扩展字段。未核实的御魂指标枚举、组合语义和数值单位保留原值，**不会据此宣布整队配置可组成**。旧版 V0 中无法判定角色类型的空配置会明确拒绝，避免猜错阴阳师身份。

## 在线更新范围

- 国服名单、40级6星基础属性与式神原始图片来自网易公开接口/CDN。默认查询若只返回子集，会按官网八类筛选重建名单，并与静态目录校验。
- 应用运行期间每日检查一次；已知属性每7天、图片每30天复核，缺失本地文件优先补充。完整复核会遍历已有属性和图片，耗时较长；可取消。
- 图片下载后检查格式、尺寸、完整解码和 SHA-256。失败时保留对应旧资料；取消或收到 401/403/429 时停止并保留更新前清单。断网可继续使用内置资料和此前缓存。
- 晴明、神乐、源博雅、八百比丘尼的8张立绘/头像来自网易繁中官网，支持刷新；仅用于形象展示，不作为国服属性或上线时间证据。
- 源赖光、藤原道长的2张立绘来自 BWiki 社区百科，已本地化，**暂不参加官方自动更新**；缺少独立头像时按原比例缩略展示立绘。
- 最新维护公告可刷新。攻略阵容、活动配置、御魂计算规则和程序本体仍随版本发布，公告不会自动生成可靠阵容。

## 数据覆盖与限制

内置155条有阵容码的记录、35个副本用途标签、6条有成员文字资料的参考记录（含部分成员待核实）；275个官方式神、936张适用形态的式神图片，以及6位主角的10张图片，共946张形象文件。

用户 Excel 的145处原码、110个唯一原码及来源信息均保留。旧第三方服务全部拒绝这110个短码；新版已确认它们需要游戏会话的 `lineup_assisant_logic.get_share_lineup_data` 回包。v0.4.0 已真实扫码并连续两次成功查询示例「个突/寮突」的6个位置；其余原码未逐一在线验证。内置快照仍保留未解析原码，运行时可逐条查询并保存。攻略文字整理与真实解码结果分别标注。

原生长方形卡面核验数仍为0，立绘不冒充原生卡面；历史正式上线日期没有逐项补齐。N/SP/UR及ID401的无独立觉醒形象按官网页面规则处理，属性接口冲突保留证据。阵容要求涉及这些角色时展示默认形象并注明无独立觉醒形态。

平安志样例未提供阴阳师/英杰与当前穿戴归属，不能推断账号拥有状态。低等级/低星级不套用40级6星基础属性。大仓库使用有上限的候选搜索，未命中只标为待核对；已找到的全队方案检查式神和御魂实例不重复。配速关系、最高属性、契灵和战斗增益尚未完整建模。副本方案仍有缺口，未进行游戏内实战验证。

验证结果见 [v0.4.0 解析与安装验证](verification/RESULTS-v0.4.0.md)、[安装包历史验证记录](verification/RESULTS-v0.3.1.md)、[v0.3.0 功能验证记录](verification/RESULTS-v0.3.0.md)、[基础覆盖报告](verification/coverage.json) 和 [官方更新报告](verification/official-update-report.json)。

## 本地存储

桌面版在 Electron `app.getPath('userData')` 下保存 `library-v1.json`，Windows通常位于 `%APPDATA%/阴阳师阵容图鉴/`。安装位置与该目录分离，升级和默认卸载不会删除该文件。官方更新独立使用 `official-cache/manifest.json`、`images/` 和 `settings.json`，不会覆盖账号或个人阵容。

原始Excel、用户平安志示例、个人备份、测试用用户目录均不进入仓库和发行包。更新缓存目录只包含公开资料。

## 开发与构建

```powershell
npm ci
npm test
npm run build:login
npm start
npm run dist
```

`release/` 输出 Windows x64 NSIS Setup 安装包，应用文件安装到选定目录后直接运行。Electron启用上下文隔离、沙箱、关闭Node集成，限制导航、IPC来源及缓存图片访问路径。发行包中的 `data/bundle.json` 可直接离线使用。

```powershell
npm run build:data
node tools/preview.cjs
user-data\ta-build-venv\Scripts\python.exe -m unittest discover -s tests -p "test_ta_*.py" -v
```

构建登录模块需要本机 Python 3.10+，构建脚本安装锁定版本依赖并通过PyInstaller生成独立运行时；最终安装包无需用户另装Python。登录模块源码位于 `desktop/ta-python/`，`npm run dist` 会先构建该模块。

本地预览仅监听 `127.0.0.1:4173`；解码端点只接收同源请求。扫码登录、官方自动更新和桌面存储在EXE内验证；浏览器预览仅支持离线解析，不创建登录服务。维护脚本 `tools/collect.py` 需要 Pillow/openpyxl；`tools/embed-official-cache.cjs` 可从明确提供的公开资料缓存生成内置主角资源，`tools/supplement-actors.cjs` 可显式重取两位社区补图。私人输入和完整网页正文不随仓库分发。
