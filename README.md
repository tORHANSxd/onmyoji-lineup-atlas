# 阴阳师阵容图鉴

Windows x64 本地工具，支持 PVE 阵容检索、TA 阵容内容解析、形象资料在线更新与平安志库存核对。**阵容攻略快照截至 2026-09-12；官方名单、基础属性、图片和维护公告可以在线更新。**

## 下载与使用

从 [v0.6.0 Release](https://github.com/tORHANSxd/onmyoji-lineup-atlas/releases/tag/v0.6.0) 下载 `Onmyoji-Lineup-Atlas-Setup-0.6.0-Windows-x64.exe`，双击进入中文安装向导，可选择安装目录；安装完成后从桌面或开始菜单打开程序，无需安装 Node.js 或 Python。此版本未签名。仓库和发布附件已公开。

安装包默认安装到当前用户，可在Windows“已安装的应用”中卸载。账号库和官方缓存保存在独立用户数据目录，卸载默认保留；从旧便携版切换时，关闭旧版后安装即可，无需重新导入账号。

每次启动首先显示扫码页并自动获取网易官方登录二维码。用阴阳师手游内的「扫码登录」扫描、在手机确认后，软件才会载入本地资料并开放功能。扫码尚未确认、登录失败或退出登录时，阵容库、导入导出、解析及更新都不可使用。关闭软件后需要重新扫码，不提供跳过登录或离线启动入口。

无需使用主号；可以使用自己的小号或经授权使用的小号。扫码账号与主动导入的平安志库存账号可以不同，不要求绑定为同一账号。

1. 登录并选定已有查询角色后，自动遍历库内所有未解析原码。每条成功结果立即存到本机，已有缓存直接复用。「阵容库」与「阵容码查看」均显示进度，可暂停、继续；连接异常、限流或连续失败时保留已完成内容并暂停。
2. 在「阵容库」按分类、副本、文字或多个式神筛选；多个式神表示同时包含。每条原码支持单独重新解析，成功后保留已有名称、用途和备注。同一文字码至少间隔60秒，整个查询队列逐条执行，请勿频繁重复解析。
3. 「阵容码查看」支持粘贴 `|TA|…` 文字码、`#TA#` 自创二维码文本、裸 `lineup_data`，或导入二维码图片。文字码通过网易查询，完整内容在本机解析；成功后自动保存，另可编辑名称与备注。更换查询账号或角色使用左侧「登录账号 / 切换角色」。
4. 在「我的账号」导入平安志 `mumu-snapshot-v1` JSON。相同类型多只式神按实例 ID 保留，列表每页60或120条，支持名称、ID和培养素材筛选。已补齐达摩名称，包括 ID 412「奉为达摩」。默认替换同账号快照，可选增量合并；重启后资料仍在。
5. 导入、切换账号或解析完成后，自动检查阵容并按已知条件差距排序。账号页展示最接近的6条；详情逐成员列出式神、技能、套装、主属性、八项面板的要求、实际值与缺口，以及需在游戏内核对的条件。
6. 展开「我的账号 → 御魂计算器」，选择目标阵容与式神，查看六位置御魂实例和换装后面板；「深入计算全队」扩大候选范围并检查全队实例占用。缺御魂时给出套装、位置、主属性和强化优先建议；强化结果随机，兑换或提升后重新导入再核对。
7. 「式神图鉴」的资源对象可切换为「阴阳师 / 英杰」。所有图片保持原始比例并注明来源。
8. 「来源与覆盖」可手动更新官方资料、停止更新、关闭每日自动检查，或选择完整复核已有图片与属性。

阵容详情中的式神与阴阳师保持单行并排，小窗口可使用左右按钮或横向滚动查看；列表和详情均支持复制原码。界面采用宣纸、朱砂与描金配色，使用本地已有游戏立绘。

本版删除20条没有阵容码的参考记录。升级启动时会清理个人库中的无码记录；恢复备份时跳过这些记录。账号、御魂和带原码的未解析阵容保留。新增手工配置与结构化导入必须提供非空 `code`。

侧栏支持导出和恢复备份。**备份包含主动导入的库存账号资料**，请个人保存；不要当作公开阵容 JSON 上传。本工具不将扫码登录凭据保存到本地文件，也不向开发者或第三方服务器上传登录账号信息；扫码认证、角色读取及指定分享键查询仅与网易官方服务通信。凭据只在本次进程内存中使用，退出登录或关闭程序会清除，不提供密码输入框或自动恢复登录。用户主动导入的平安志库存和保存的阵容仍保存在本机，不随扫码上传。在本次登录有效期间，自创二维码解码与已保存阵容查看不需要再次联网；官方更新只请求公开资料。

## 批量添加自己的阵容

点击软件右上角「批量添加」，粘贴整批阵容码，或读取 UTF-8 编码的 TXT / TSV 文件。最简单的格式是**每行一个完整阵容码**；需要名称、用途、备注时，按下面的顺序用两个英文竖线 `||` 分隔。示例中的占位文字需要替换为自己的原码：

```text
阵容码 || 名称 || 副本/用途 || 备注
在此粘贴完整阵容码 || 魂土速刷 || 魂土 || 配速与操作说明
在此粘贴另一条完整阵容码 || 契灵阵容 || 契灵
在此粘贴第三条完整阵容码
```

软件内有「复制格式模板」。也可以从 Excel 等表格直接复制四列，制表符会自动分列；不直接读取 XLSX 文件。名称、用途、备注均可省略，但中间空列须保留，例如 `完整阵容码 || || 魂土`。字段保持单行，不包含 `||` 或制表符。空行、表头和以 `//` 开头的注释跳过；单次最多1000条、5 MiB，名称最多200字、用途100字、备注8000字。

预览列出行号、重复码和格式错误，可筛选或展开更多行。点击「添加 N 条有效阵容」后只保存有效的新码；重复码保留首次记录，库内已有名称、备注和解析缓存不覆盖。整批超过条数或体积限制时不能添加。预览只验证格式，分享码是否过期、成员和具体要求以解析结果为准。

默认勾选「添加后自动解析新码，并继续库内剩余内容」。若已有解析正在进行，会等当前条目保存后优先解析新码，再继续其余内容；文字码仍遵守原有请求间隔和同码60秒冷却。完整 `#TA#` / Base64 内容使用本机解析器，裸 Base64 会统一保存成 `#TA#` 格式，避免重复。没有选定查询角色时，先在左侧「登录账号 / 切换角色」选择角色。

取消自动解析也可以先收录原码。添加后点击「查看已添加阵容」，会进入「我保存的」并按「最近添加」排序；其后可随时从卡片解析、复制原码、查看详情，导出备份会包含新增记录。保存失败时本批不会留在内存库中，输入仍保留供重试。

## TA 解析范围

| 输入 | 行为 |
|---|---|
| `#TA#<Base64>` 自创二维码文本 | 本地 Base64 → zlib → MessagePack → V0–V3 展开 |
| 裸 Base64 `lineup_data` | 同上 |
| 阵容二维码图片 | 本机识别二维码，然后调用同一个解析器 |
| `{ "share_key": "…", "lineup_data": "…" }` JSON | 解码并关联原始文字分享码；支持 JSON 数组批量导入 |
| 文字分享码 `\|TA\|<share_key>` | 网易官方扫码授权 → 选择已有角色 → 查询并本机解码；可保存离线使用 |
| `#TA#<数字>` 官方阵容编号 | 提示需要游戏官方阵容配置表 |

实现依据用户指定的解析研究任务、12组参考向量与2.8.84 APK静态逻辑核对，细节见 [TA 协议说明](docs/TA_PROTOCOL.md) 和 [御魂计算口径](docs/SOUL_CALCULATOR.md)。支持成员、技能、觉醒、御魂配置、契灵、AI技能及扩展字段。已核对的八项数值范围、主属性位置、套装件数、额外属性和最高属性次序参与计算；未核实或导出缺失的条件单列待核对。旧版 V0 中无法判定角色类型的空配置会明确拒绝，避免猜错阴阳师身份。

## 在线更新范围

- 国服名单、40级6星基础属性与式神原始图片来自网易公开接口/CDN。默认查询若只返回子集，会按官网八类筛选重建名单，并与静态目录校验。
- 应用运行期间每日检查一次；已知属性每7天、图片每30天复核，缺失本地文件优先补充。完整复核会遍历已有属性和图片，耗时较长；可取消。
- 图片下载后检查格式、尺寸、完整解码和 SHA-256。失败时保留对应旧资料；取消或收到 401/403/429 时停止并保留更新前清单。断网可继续使用内置资料和此前缓存。
- 晴明、神乐、源博雅、八百比丘尼的8张立绘/头像来自网易繁中官网，支持刷新；仅用于形象展示，不作为国服属性或上线时间证据。
- 源赖光、藤原道长的2张立绘来自 BWiki 社区百科，已本地化，**暂不参加官方自动更新**；缺少独立头像时按原比例缩略展示立绘。
- 最新维护公告可刷新。攻略阵容、活动配置、御魂计算规则和程序本体仍随版本发布，公告不会自动生成可靠阵容。

## 数据覆盖与限制

内置155条有阵容码的记录、35个副本用途标签、6条有成员文字资料的参考记录（含部分成员待核实）；275个官方式神及5种APK确认的培养素材、936张适用形态的式神图片，以及6位主角的10张图片，共946张形象文件。新增素材没有伪造头像，以名称首字占位。

用户 Excel 的145处原码、110个唯一原码及来源信息均保留。旧第三方服务全部拒绝这110个短码；新版已确认它们需要游戏会话的 `lineup_assisant_logic.get_share_lineup_data` 回包。v0.4.0 已真实扫码并连续两次成功查询示例「个突/寮突」的6个位置；其余原码未逐一在线验证。内置快照仍保留未解析原码，v0.5.0运行时自动遍历并保存；失败条目显示原因并可重试。攻略文字整理与真实解码结果分别标注。

原生长方形卡面核验数仍为0，立绘不冒充原生卡面；历史正式上线日期没有逐项补齐。N/SP/UR及ID401的无独立觉醒形象按官网页面规则处理，属性接口冲突保留证据。阵容要求涉及这些角色时展示默认形象并注明无独立觉醒形态。

平安志样例未提供阴阳师/英杰、契灵与当前穿戴归属，不能推断这些条件已满足。基础面板优先使用实际实例的 `attrs` 与APK觉醒加成；缺少这些数据时，低等级/低星级不套用40级6星属性。大仓库使用有上限的候选搜索，未命中不等于无法配出；已找到的全队方案检查式神和御魂实例不重复，以及原码最高属性的先后约束。只有已知配置均满足且没有待核对项时才显示「配置可组成」；其余区分「式神御魂就绪 · 仍需核对」「存在缺口」与「需核对」。差距分用于排序，不是通关率。战斗被动、御魂四件效果的实战触发、未写入原码的操作条件仍需游戏内确认。

验证结果见 [v0.6.0 批量添加验证](verification/RESULTS-v0.6.0.md)、[v0.5.0 批量解析、账号与计算验证](verification/RESULTS-v0.5.0.md)、[v0.4.1 启动登录验证](verification/RESULTS-v0.4.1.md)、[v0.4.0 解析与安装验证](verification/RESULTS-v0.4.0.md)、[基础覆盖报告](verification/coverage.json) 和 [官方更新报告](verification/official-update-report.json)。

## 本地存储

桌面版在 Electron `app.getPath('userData')` 下保存 `library-v1.json`，Windows通常位于 `%APPDATA%/阴阳师阵容图鉴/`。安装位置与该目录分离，升级和默认卸载不会删除该文件。官方更新独立使用 `official-cache/manifest.json`、`images/` 和 `settings.json`，不会覆盖账号或个人阵容。

原始Excel、用户平安志示例、个人备份、测试用用户目录均不进入仓库和发行包。更新缓存目录只包含公开资料。

## 开发与构建

```powershell
npm ci
npm test
npm run build:login
npm start
npm run dist
```

`release/` 输出 Windows x64 NSIS Setup 安装包，应用文件安装到选定目录后直接运行。Electron启用上下文隔离、沙箱、关闭Node集成，限制导航、IPC来源及缓存图片访问路径。发行包中的 `data/bundle.json` 可直接离线使用。

```powershell
npm run build:data
node tools/preview.cjs
user-data\ta-build-venv\Scripts\python.exe -m unittest discover -s tests -p "test_ta_*.py" -v
```

构建登录模块需要本机 Python 3.10+，构建脚本安装锁定版本依赖并通过PyInstaller生成独立运行时；最终安装包无需用户另装Python。登录模块源码位于 `desktop/ta-python/`，`npm run dist` 会先构建该模块。

本地预览仅监听 `127.0.0.1:4173`；浏览器只显示启动登录页，不创建登录服务或开放软件界面。扫码登录、官方自动更新和桌面存储在EXE内验证。`tools/verify-login-ui.cjs` 使用真实 Electron 页面和预加载脚本、合成认证状态检查界面切换，该测试程序不进入安装包，生产程序没有跳过登录的测试开关。维护脚本 `tools/collect.py` 需要 Pillow/openpyxl；`tools/embed-official-cache.cjs` 可从明确提供的公开资料缓存生成内置主角资源，`tools/supplement-actors.cjs` 可显式重取两位社区补图。私人输入和完整网页正文不随仓库分发。
